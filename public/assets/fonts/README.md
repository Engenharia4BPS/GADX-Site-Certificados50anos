# Fontes do certificado

As fontes são servidas pelo próprio site. Não há chamadas a serviços externos de fontes.

- **Source Serif 4**, romano variável: títulos, indicativo e numeral comemorativo. Arquivo original `WOFF2/VAR/SourceSerif4Variable-Roman.ttf.woff2` do [repositório oficial](https://github.com/adobe-fonts/source-serif), revisão `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`.
- **Source Sans 3**, romano variável: contadores, legendas e informações auxiliares. Arquivo original `WOFF2/VF/SourceSans3VF-Upright.ttf.woff2` do [repositório oficial](https://github.com/adobe-fonts/source-sans), revisão `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e`.

Os binários foram copiados sem alterações. As licenças SIL Open Font License 1.1 originais estão nesta pasta e devem acompanhar a distribuição.

Publique toda esta pasta em `public_html/50anos/assets/fonts/`, junto com as atualizações de `site.css` e `award.js`. Os algarismos do certificado usam alinhamento uniforme (`lining-nums`); o indicativo e os contadores também usam largura numérica uniforme (`tabular-nums`).
